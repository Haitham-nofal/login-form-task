# Java Swing Login Form Task

A Java GUI application built using AWT/Swing for a Login Form with role-based user authentication.

## Features
- Swing UI Components (`JFrame`, `JTextField`, `JPasswordField`, `JComboBox`, `JButton`).
- Dynamic welcome page after successful login.
- Sample users provided for testing (Student, TA, Professor).

## How to Run
```bash
javac LoginFormTask.java
java LoginFormTask
